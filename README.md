# Yimpop V.10

This project is open to anyone who wish to contribute to this AI model.
The main idea is to create a model that can create something unique and 
free available to support gamers, visual effects, sound auditors and 
video editors along side with music production.

As the project begins, lets try with these few genres and later extended to others.

# The model handles
Genres: Afrobeat , Bongofleva , Dancehall, Reggae , Hip-Hop , Trap, Country, Rnb , Blues and Spanish
Videos: Cartoons , Short Film
Sounds: nature, Animals, Machines , Midi , Instrumentals, Vocals
Text: Film Script, Music lyrics, Documents & Code
Softwares: VST, Games & Mini OS ( Windows & Linux )
